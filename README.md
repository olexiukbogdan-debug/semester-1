# semester-1

Лабораторна робота з Python:

- перша програма `Hello, world!`;
- створення змінних типів `int`, `float`, `str`, `bool`, `list`, `tuple`, `dict`, `set`;
- виведення значень змінних та їхніх типів;
- використання операторів `+`, `-`, `*`, `/`, `%`, `//`, `**`.

## Запуск

```bash
python main.py
```
