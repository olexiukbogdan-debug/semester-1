# Лабораторна робота 5 — «Алхімік»

Графічна RPG: гравець збирає інгредієнти, варить зілля й продає їх у вікні гри.

## Запуск

```bash
python lab5\main.py
```

## Правила

- У каталозі є 200 різних інгредієнтів і 50 видів зіль.
- На початку кожного ігрового дня гравець отримує 5 різних інгредієнтів.
- Інвентар має до 25 слотів для інгредієнтів (до 25 одиниць одного виду) і до 10 слотів для зіль (до 10 зіль одного виду).
- Для кожного зілля потрібні будь-які 2 з 4 вказаних у рецепті інгредієнтів.
- Зілля продаються за вказаною в каталозі ціною.
- Перемога: зібрати щонайменше 300 золотих. Поразка: не досягти цієї суми за 20 ігрових днів.

## Перевірка правил

```bash
python -m unittest discover -s lab5 -v
```
